# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Readers, clients, collaborators, peers, and visitors exploring portfolio work, essays, guides, stories, and curated writings.

## Product Purpose

A versatile, high-performance static website that seamlessly unites an impactful personal portfolio & project showcase with a rich, distraction-free reading experience for essays, stories, guides, and writings. Success means visitors can discover work, stories, and ideas immediately with clear visual hierarchy and typographic polish.

## Positioning

A markdown-native portfolio and knowledge engine built on Next.js 16, React 19, and Tailwind CSS v4. Content authors write markdown files with standard front matter and get a modern, responsive showcase with full client-side search, theme toggle, and rich code formatting.

## Operating Context

Evaluated in desktop and mobile browsers across varied screen sizes and lighting environments (dark and light modes). Maintained by editing markdown and front matter files directly in Git, statically deployed to modern hosting platforms (Vercel, Cloudflare, GitHub Pages).

## Capabilities and Constraints

- Next.js 16 (App Router) with React 19 and Tailwind CSS v4.
- Remark/Rehype markdown rendering with code syntax highlighting and Mermaid diagrams.
- Client-side search with modal palette and keyboard shortcuts.
- Theme switching (light/dark/system).
- Static generation compatibility with fast initial paint and fluid navigation.

## Brand Commitments

- Modern, professional, high-craft visual standard fitting both creative work and deep technical articles.
- Cohesive design system connecting the homepage portfolio feed to long-form reading pages.

## Evidence on Hand

- Markdown content files in `content/` (`homepage.md`, `settings.md`, `theme.md`, `01-guides/`, `02-tutorials/`, `03-sample/`).
- Established UI components in `src/components/` and layout templates in `src/app/`.

## Product Principles

1. **Dual-Nature Harmony**: Seamlessly transition from a high-impact portfolio showcase to a distraction-free reading experience for long-form writings and articles.
2. **Markdown-First Speed**: Content stays in markdown; runtime performance remains instantaneous and statically optimized.
3. **Typographic & Spatial Polish**: Intentional type hierarchy, fluid spacing, and restrained accents that feel custom and contemporary.
4. **Flawless Multi-Device Ergonomics**: Equal scanability, touch responsiveness, and visual clarity across mobile, tablet, and desktop viewports.
