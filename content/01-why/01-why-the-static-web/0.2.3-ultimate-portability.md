Vendor lock-in disappears when content lives as clean version-controlled files:

- **Plain Markdown files**: Edit with VS Code, Obsidian, Cursor, or any plain text editor.
- **Git revision history**: Every edit, rollback, and revision is tracked via standard Git commits.
- **Zero migration lock**: Migrate frameworks whenever you want—your content remains intact and universally readable without exporting database dumps.
