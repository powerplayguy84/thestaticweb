# Category Index Template

This file is optional but recommended for category folders. It allows you to:

1. **Define a custom display title** for the category (instead of using the folder name)
2. **Add a description** that can be used in navigation or category pages
3. **Control ordering** through the folder name prefix (e.g., `01-guides`, `02-tutorials`)

## Frontmatter Options

- `title`: The display name for this category (required)
- `description`: A brief description of the category content (optional)

## Folder Naming Convention

Categories should be named with a numeric prefix to control their display order:

```
01-guides/
  index.md
  01-article-one.md
  02-article-two.md
02-tutorials/
  index.md
  01-getting-started.md
  02-advanced-topics.md
```

The numeric prefix determines the order in navigation and mobile menus.
