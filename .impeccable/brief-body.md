# Surface Brief: Modern Portfolio & Markdown Knowledge Hub

## Scope
Homepage portfolio showcase and markdown article/README reading experience across mobile and desktop.

## Direction contract

THESIS: Refuses the static, generic blog template rut. Merges ultra-clean Swiss editorial restraint with modern interactive excitement: luminous micro-borders, fluid typography, subtle mesh aura depth, and tactile category telemetry that effortlessly shifts between portfolio project showcasing and rich, distraction-free markdown article reading.

OWN-WORLD: Sophisticated obsidian-slate backdrop with crisp typography, ambient frosted glass elevation, subtle electric blue/cyan and emerald accents (`#3b82f6`, `#06b6d4`, `#10b981`), fine 1px hairline borders (`border-border/60`), and smooth hover glow illumination.

STORY: The visitor lands on a high-craft engineering portfolio with clear identity and active project highlights, explores live interactive work samples, and transitions directly into technical README articles and guides without any visual dissonance.

FIRST VIEWPORT: Compact, high-impact hero with developer badge, clean title with subtle gradient accent, quick bio, social/repo chips, and an interactive featured showcase track followed by a sticky category filter rail.

FORM: The Minimalist Studio Monograph (clean modern & exciting), position 2, seed:35b3edfc2651c2b2.
